¿Qué es HTML?

HTML (HyperText Markup Language) es el lenguaje de marcado utilizado para estructurar el contenido de las páginas web. Define elementos como títulos, párrafos, enlaces, imágenes, formularios y diferentes secciones de una página.

HTML no se encarga principalmente del diseño visual ni de la lógica de una página. CSS se utiliza para el diseño y JavaScript para agregar comportamiento e interactividad.

Estructura Básica

<!DOCTYPE html>
<html>
<head>
    ...
</head>
<body>
    ...
</body>
</html>

Textos y Títulos

Títulos

<h1>
<h2>
<h3>
<h4>
<h5>
<h6>

Las etiquetas <h1> a <h6> se utilizan para crear títulos y subtítulos. <h1> representa el título principal y <h6> el nivel de menor importancia. Los títulos permiten organizar jerárquicamente el contenido de una página. 

<h1>Título principal</h1>
<h2>Subtítulo</h2>
<h3>Subtítulo de nivel 3</h3>

Párrafo

La etiqueta <p> se utiliza para definir un párrafo de texto. Es una de las etiquetas más utilizadas para presentar contenido escrito.

Ejemplo:

<p>Este es un párrafo de ejemplo.</p>

Enlaces

Enlaces Básicos

La etiqueta <a> se utiliza para crear enlaces o hipervínculos. El atributo href indica la dirección o destino al que llevará el enlace cuando el usuario haga clic.

Ejemplo:

<a href="pagina.html">Texto del enlace</a>

Enlaces externos

Los enlaces externos permiten dirigir al usuario hacia otra página web o sitio diferente al sitio actual. 

<a href="https://www.google.com">Ir a Google</a>

Abrir en otra pestaña

El atributo target="_blank" permite abrir un enlace en una nueva pestaña del navegador. 

<a href="https://www.google.com" target="_blank">
    Abrir Google
</a>

Enlaces internos

Los enlaces internos permiten navegar hacia diferentes partes de una misma página utilizando el atributo id. 

<a href="#contacto">Ir a contacto</a>

<section id="contacto">
    <h2>Contacto</h2>
</section>

Imágenes

Etiqueta <img>

La etiqueta <img> se utiliza para insertar imágenes en una página web. No necesita una etiqueta de cierre. 

<img src="imagen.jpg" alt="Descripción de la imagen">

Atributos principales

El atributo src indica la ubicación de la imagen. El atributo alt proporciona una descripción alternativa y es importante para la accesibilidad. 

<img src="foto.jpg" alt="Foto de ejemplo">

Listas

Lista desordenada

La etiqueta <ul> crea una lista desordenada. Cada elemento de la lista se define mediante la etiqueta <li>. 

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Lista ordenada

La etiqueta <ol> crea una lista ordenada. Los elementos aparecen numerados automáticamente. 

<ol>
    <li>Primero</li>
    <li>Segundo</li>
    <li>Tercero</li>
</ol>

Tablas

Estructura de una tabla

La etiqueta <table> se utiliza para crear tablas. <tr> representa una fila, <th> una celda de encabezado y <td> una celda de datos. 

<table>
    <tr>
        <th>Nombre</th>
        <th>Edad</th>
    </tr>
    <tr>
        <td>Juan</td>
        <td>25</td>
    </tr>
</table>

Encabezado y cuerpo

Las etiquetas <thead> y <tbody> permiten organizar semánticamente el encabezado y el contenido de una tabla. 

<table>
    <thead>
        <tr>
            <th>Producto</th>
            <th>Precio</th>
        </tr>
    </thead>

    <tbody>
        <tr>
            <td>Teclado</td>
            <td>$20.000</td>
        </tr>
    </tbody>
</table>

Formularios

Estructura básica

La etiqueta <form> se utiliza para crear formularios que permiten recopilar información introducida por el usuario. 

<form>
    ...
</form>

Label e Input

La etiqueta <label> identifica un campo del formulario. La etiqueta <input> permite al usuario introducir diferentes tipos de información. 

<label for="nombre">Nombre:</label>
<input type="text" id="nombre">

Otros elementos

HTML proporciona diferentes elementos para formularios, como <textarea>, <select>, <option> y <button>. 

<textarea></textarea>

<select>
    <option>Opción 1</option>
    <option>Opción 2</option>
</select>

<button>Enviar</button>

Multimedia

Video

La etiqueta <video> permite incorporar archivos de video directamente en una página web. 

<video controls>
    <source src="video.mp4" type="video/mp4">
</video>

Audio

La etiqueta <audio> permite incorporar archivos de audio. 

<audio controls>
    <source src="audio.mp3" type="audio/mpeg">
</audio>

Iframe

La etiqueta <iframe> permite insertar contenido externo dentro de una página, como mapas, videos u otras páginas web. 

<iframe src="https://www.ejemplo.com">
</iframe>

HTML Semántico

¿Qué es la semántica?

HTML semántico utiliza etiquetas que describen claramente el significado y la función del contenido. Esto mejora la organización, accesibilidad y comprensión de una página web.

Etiquetas principales

Algunas de las etiquetas semánticas más utilizadas son <header>, <nav>, <main>, <section>, <article>, <aside> y <footer>. 

<header>
    Encabezado
</header>

<nav>
    Navegación
</nav>

<main>
    Contenido principal

    <section>
        Sección
    </section>

    <article>
        Artículo
    </article>
</main>

<footer>
    Pie de página
</footer>

¿Por qué utilizar HTML semántico?

Las etiquetas semánticas permiten estructurar mejor el contenido, facilitan el mantenimiento del código y ayudan a los navegadores, buscadores y tecnologías de asistencia a comprender la estructura de la página.
